# TINDER_Bloc_2
**Projet_Tinder**_Bloc_2
Enquête sur les expériences de dating de participants des deux sexes

**Questions à se poser :**
      - quelles sont les raisons qui poussent les participants à s'inscrire aux dating ?
      - quelles sont les caractéristiques les plus importantes selon les classes d'age ?
      - Corrélation ou non-corrélation entre :
      
             - ce que les hommes pensent que les femmes recherchent, et ce que recherchent les femmes ?
             
             - ce que les femmes pensent que les hommes recherchent, et ce que recherchent les hommes ?

**Proposition :**

             - graphique en histogramme représentant les sources de motivation d'inscription triées par sexe
     
             - graphique en histogramme représentant les caractéristiques les plus importantes selon le sexe et les classes d'age
     
             - graphique en histogramme comparant ce que pensent les hommes et ce que recherchent les femmes

             - graphique en histogramme comparant ce que pensent les femmes et ce que recherchent les hommes
